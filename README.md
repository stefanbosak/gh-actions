# GitHub Actions Collection

A collection of reusable GitHub composite actions for common CI/CD tasks.

| Action | Description |
|--------|-------------|
| [cleanup-dockerhub-old-digests](https://github.com/stefanbosak/gh-actions/blob/main/cleanup-dockerhub-old-digests/README.md) | Delete obsolete image manifests from DockerHub after a successful build |
| [get-repo-description](https://github.com/stefanbosak/gh-actions/blob/main/get-repo-description/README.md) | Fetch a GitHub repository's description via the API |
| [monitor-release](https://github.com/stefanbosak/gh-actions/blob/main/monitor-release/README.md) | Monitor a repository for new releases and fire a dispatch event when one is detected |
| [ms-teams-simple-notifier](https://github.com/stefanbosak/gh-actions/blob/main/ms-teams-simple-notifier/README.md) | Send formatted status notifications to Microsoft Teams |
| [signed-verified-commit](https://github.com/stefanbosak/gh-actions/blob/main/signed-verified-commit/README.md) | Commit and push files as a signed, verified commit via the GitHub GraphQL API |
